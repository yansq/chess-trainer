Downloaded 2026-10-23. See sources.json for original checksums, edits, gain and measured results. Converted to mono 48 kHz PCM16 WAV for local Web Audio decoding. Only quiet edges were trimmed and constant gain applied; timbre, pitch and dynamic range are preserved. For these short effects, loudness comparisons use the same one-second measurement window with silence padding; the padding is not included in the delivered sounds.

Runtime audio is loaded exclusively from bundled assets; no Chess.com or other network service is contacted for playback.
