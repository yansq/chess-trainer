# Chess Trainer 0.2.5

- 修复 Lichess 同步时部分棋谱地址被误判为 ID 不一致的问题，兼容 `/game/ID`、旧地址及 `GameId`，保留身份一致性校验。
- 内置 Chess.com 默认走子、吃子、将军录音，统一响度并提高整体音量，支持离线播放；处理连续走子、静音及音频加载失败。
- 开局统计的日期默认显示“不限”，支持选择与清空日期。
- 题目说明在揭晓答案或完整答对后展示；创建题目时自动带入当前招法笔记。
- 复盘招法列表为含笔记的招法显示棕底白色圆形徽标，支持主线与试走分支。
- 精简 React Hook、重复状态和冗余转换，保留异步取消保护。
- 纳入现有 OpenSpec 工作流配置。

适用于 macOS Apple Silicon。可在“设置 → 应用更新”检查安装，首次安装下载 `.app.zip`。应用采用 ad-hoc 签名，尚未进行 Apple 公证。
