# Chess Trainer 0.2.0

- 新增「设置 → 应用更新」：检查 GitHub 正式版本、查看更新说明、下载安装并自动重启。
- 更新包使用 Tauri 官方 Updater 签名校验；签名或下载失败时保留当前版本并支持重试。
- 全站采用 Radix Themes，使用低饱和度灰绿主题，完善紧凑布局。
- 复盘页新增引擎开关和返回对局列表按钮，修复引擎推荐变化排版。
- 开局统计新增整体胜率和得分率，移除柱状图。
- 题库新增到期时间，到期预告改为累计统计。

本次为首次支持应用内更新的版本。旧版 0.1.0 需手动安装一次：下载 Apple Silicon 的 .app.zip，解压后把 Chess Trainer.app 放入「应用程序」。之后在「设置 → 应用更新」更新即可，原有本地棋谱、题库和复习记录会保留。

适用 macOS Apple Silicon（arm64）。应用采用 ad-hoc 签名，尚未进行 Apple 公证；首次打开时可能需要在系统「隐私与安全性」中允许打开。
