# 代码消融实验 · 2026-10-15

后续样式决策：按用户要求已恢复 Tailwind Vite 编译，并将全部页面和组件样式统一迁移到 Tailwind 工具类。本报告记录的是消融实验当时的结果；其中移除样式编译层的决定及对应构建指标已被后续变更覆盖，其他简化保留。

以本轮开始时的工作区为基线，保留之前未提交的功能改动。检查范围覆盖前端页面、共享模块、Rust 引擎/持久化/同步边界和工程配置；删除项以引用检查、差分对比及回归验证为依据。本轮不修改数据库结构、不删除产品功能。

## 已采用的消融

| 项目 | 原有设计 | 简化结果 | 验证 |
| --- | --- | --- | --- |
| 通用按钮 | 一个调用点，却支持多态 `asChild`、variant、类名合并 | 改为原生按钮，删除 Button、cn 工具及失效的 shadcn 配置 | 设置页 24 个关键元素的尺寸、字体、边框、间距、颜色和 display 均与基线一致；保存用户名交互通过 |
| 样式编译层 | 整个界面使用应用 CSS，仅通用按钮使用工具类 | 移除 Tailwind Vite 插件和工具类编译；保留 `preflight.css` 基础重置 | 设置、筛选、复盘和训练页面回归通过 |
| PGN 重复回放 | `loadPgn/history` 后，再创建 Chess 对象重走整局 | 直接使用历史 Move 的 SAN、UCI 信息及 before/after FEN | 30 局完整 Game 对象逐项深比较一致；包含吃过路兵、王车易位、升变和自定义起始局面 |
| 训练展示状态 | attempt 和 revealed 两套可独立变化的状态 | 从 attempt 是否非空推导是否展示答案，复用 tryMove 返回类型 | 落子前隐藏答案/注释，落子后显示，评级后清除；页面回归通过 |
| 引擎重复摘要 | FEN、候选数组之外，再复制首项深度、评价、PV、bestMove | IPC 只传 FEN 和候选数组，消费者直接读取首项 | 解析、缓存往返、流式分析及真实 Stockfish 测试通过 |
| 失误候选数据 | 保留走前、走后两份完整分析对象 | 仅保留出题所需的最佳招法、参考变化、损失与分类 | 分类结果、最佳答案及参考变化测试通过 |
| 引擎共享所有权 | 未使用的 EngineManager Clone，以及两层外部 Arc | Manager 直接拥有两把锁；保留任务取消真正需要的 Arc/Weak | 真实引擎进程复用、独立取消、排队取消、退出恢复测试通过 |

移除的直接依赖：`@radix-ui/react-slot`、`class-variance-authority`、`clsx`、`tailwind-merge`、`@tailwindcss/vite`。这是直接依赖数量的减少；部分包仍可能由保留的 Radix/Recharts 间接依赖。

## 反向实验与保留项

| 项目 | 实验/判断 | 结论 |
| --- | --- | --- |
| 请求生命周期失效检查 | 在隔离副本中删除 active 检查。原来 6 项测试全部通过，消融后 3 项失败：旧更新/错误被接收、离开页面后仍启动分析、旧最终结果覆盖页面 | 保留。隔离改动已回退，未进入实际工作区 |
| clockNow 薄包装 | 尝试直接使用 Date.now 后，现有 React Hooks purity 规则在评级事件回调中报 2 项错误 | 回退该项，保留现有包装，不放宽检查规则 |
| 分支树和 preferred 路径 | 主线复用、多层分支、选择线路后前进/后退都依赖这些信息 | 本轮未尝试删除，保留当前设计 |
| 同步断点、事务与解析 Worker | 分别承担暂停续传、数据/进度一致提交，以及批量棋谱解析不阻塞界面的职责 | 本轮未尝试删除，保留当前设计 |
| MultiPV 完整深度聚合与请求独立取消 | 避免混合不同深度的候选、旧任务误停新任务 | 本轮未尝试删除，保留当前设计 |
